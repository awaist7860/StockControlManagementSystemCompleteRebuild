# StockControlManagementSystemCompleteRebuild
This is a complete rebuild of a previous project called Stock Control System


## Repository structure

- `backend/` – ASP.NET Core API and application logic.
- `frontend/` – User-facing web application.
- `database/` – Database migrations, seed data and diagrams.
- `docs/` – Requirements, architecture and development documentation.
- `legacy/` – Original WinForms application retained for reference.
- `tests/` – Automated tests for the rebuilt system.
